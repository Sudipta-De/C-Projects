## 📂 Projects

### 🎮 Number Guessing Game

A console-based game where the user tries to guess a randomly generated number.

**Features:**

* Easy, Medium, and Hard difficulty levels
* Different number ranges for each level
* Limited attempts based on difficulty
* Higher/Lower hints
* Play Again option
* Random number generation using `rand()` and `srand()`

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Sudipta-De/C-Projects.git
```

### 2. Open the project folder

```bash
cd C-Projects
```

### 3. Compile a C program

```bash
gcc filename.c -o program
```

### 4. Run the program

**Windows:**

```bash
program.exe
```

**Linux/macOS:**

```bash
./program
```
